# Quiz_site
A site used to test Chinese speakers on their English skills. It features:  
-> A title page explaining the directions (in Chinese)  
-> A progress bar to see how far in the test you are (when answering questions)  
-> An end screen describing:  
  -> Your score  
  -> How well you did for each grade level of English  
  -> And a specific list of which questions the user answered wrong. :)
